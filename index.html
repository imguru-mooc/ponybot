명령: —
수동 테스트 (블루투스 연결 확인용)

※ Chrome 또는 Edge에서 실행하세요 (Firefox·Safari는 Web Bluetooth 미지원).
※ 마이크·블루투스 권한을 위해 http://localhost 로 여는 것이 가장 안정적입니다. 파일을 둔 폴더에서 py -m http.server 8000 실행 후 http://localhost:8000/ponybot_voice.html 접속.
※ ② 듣기 시작을 한 번 누르면 계속 듣습니다. 명령을 또박또박, 한 번에 하나씩 말하세요 (예: “전진” … 잠깐 멈춤 … “정지”). 다시 누르면 중지됩니다.
※ 인식 말: “전진 / 후진 / 왼쪽(좌회전) / 오른쪽(우회전) / 정지(멈춰)”.
